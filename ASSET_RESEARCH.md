### ⚠️ Gaps / Needs Attention

| Gap | Details | Suggested Approach |
|-----|---------|-------------------|
| **Tropical/Jungle Vegetation** | Pirate Pack has palm trees only; Cainos has pine/oak (temperate) | Use Pirate Pack palms + modify Cainos trees (recolor leaves green), add Foliage Sprites bushes |
| **Survivor Character Variety** | Cainos has 1 character; need idle, gather, craft, hurt, death animations | Extend Cainos sprite sheet; use Micro Roguelike as reference for poses |
| **Crafting Station Sprites** | No dedicated crafting stations (workbench, furnace, loom, etc.) | Build from Tiny Dungeon props + UI Pack icons; or custom assemble |
| **Mountain/Cliff Tiles** | Cainos has cliffs; Pirate Pack has rocky shores | Cainos cliffs (32×32) are good; supplement with Pirate Pack rocks |
| **Jungle Floor Variety** | Limited jungle-specific ground (roots, vines, fallen logs) | Combine Foliage Sprites logs/stumps + Cainos grass/dirt |
| **Resources (Ore, Wood, Fiber, Stone)** | UI Pack has icons; no world pickup sprites | Create from Tiny Dungeon gems/ores + custom pixel art |
| **Animals/Wildlife** | None in free packs | Consider: Kenney "Animal Pack" (paid), or custom simple sprites |

## Scaling Strategy for 16×16 → 32×32

| Approach | When to Use | Tools |
|----------|-------------|-------|
| **Nearest-neighbor 2×** | All pixel art (preserves crisp edges) | Aseprite, Photoshop, ImageMagick `convert -scale 200% -filter point` |
| **Manual touch-up** | After scaling: fix blurry transitions, add detail | Aseprite recommended |
| **Tile blending** | Kenney Pirate Pack water-to-sand transitions scale well | Test in-engine first |

> **Tip**: Kenney's 16×16 tiles are designed to scale cleanly. Cainos is already 32×32 native — prefer it where available to avoid scaling artifacts.
